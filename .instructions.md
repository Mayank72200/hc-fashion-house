## 🛠️ Technology Stack

### Backend
- **Framework**: FastAPI (Python)
- **Database**: Supabase (PostgreSQL)
- **Media Storage**: Cloudinary
- **Authentication**: JWT + Supabase Auth
- **ORM/Models**: SQLAlchemy + Pydantic
- **Deployment**: Google Cloud Platform (Docker containers)

### Frontend
- **Framework**: React 18
- **Build Tool**: Vite
- **Routing**: React Router v6
- **Styling**: TailwindCSS
- **UI Components**: Radix UI + shadcn/ui
- **Animations**: Framer Motion
- **State Management**: React Context API (Auth, Cart, Wishlist, Theme)
- **HTTP Client**: Axios

### Key Integrations
- Supabase for database and auth
- Cloudinary for image/media management
- Stripe (potential payment gateway)

## 💬 Communication Protocol

### When to Ask Questions:
- **Business Logic**: Payment flows, discount calculations, inventory rules
- **Design Decisions**: Major UI/UX changes, color scheme updates
- **Breaking Changes**: Anything that might affect existing functionality
- **Trade-offs**: When multiple solutions exist with pros/cons
- **Unclear Requirements**: When the intended behavior is ambiguous

### How to Report Issues:
When you find an issue, document:
1. **What's wrong**: Clear description of the bug/issue
2. **Where it is**: File path and line numbers
3. **Why it matters**: Impact on users or system
4. **Proposed solution**: How you plan to fix it (including alternatives)
5. **Risks**: Any potential side effects of the fix

### How to Propose Enhancements:
When suggesting improvements:
1. **Current state**: What exists now
2. **Proposed change**: What you want to implement
3. **Benefits**: Why this improves the system
4. **Effort**: Estimated complexity/time
5. **Trade-offs**: Any downsides or considerations
