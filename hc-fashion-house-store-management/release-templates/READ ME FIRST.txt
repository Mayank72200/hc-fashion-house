===========================================================
  HC FASHION HOUSE
  Billing and store management - read this first
===========================================================

  Your invoices, customers and settings stay on THIS
  computer. The app runs without the internet.


-----------------------------------------------------------
  STEP 1 - EXTRACT THIS FOLDER FIRST
-----------------------------------------------------------

  If you are reading this INSIDE the ZIP file, stop and
  extract it first. The app cannot run from inside a ZIP.

    1. Close this window.
    2. Right-click the HC-Fashion-House ZIP file.
    3. Choose "Extract All..." then "Extract".
    4. Open the new folder that appears.

  Keep every file together in that folder. The launcher
  needs the "_system" folder that sits next to it.


-----------------------------------------------------------
  STEP 2 - OPEN THE LAUNCHER AND CLICK INSTALL
-----------------------------------------------------------

  Double-click "HC Fashion House - WINDOWS". A small window
  opens with one button: click "Install".

  There is nothing to fill in and nothing is downloaded -
  everything the app needs is inside the ZIP. Install
  copies the app to this PC's own program folder:

    %LOCALAPPDATA%\Programs\HC Fashion House

  That folder is on this PC only - not OneDrive, not the
  Desktop, not Documents. Then the app opens in your web
  browser by itself. A black window appears while it
  works. Leave it alone - it closes on its own.

  You do NOT need administrator rights. Install adds a
  Desktop shortcut and a Start Menu entry, both called
  "HC Fashion House". Everything else stays in the program
  folder.

  Windows may warn "Windows protected your PC" because the
  launcher is not code-signed. Click "More info", then
  "Run anyway".

  Afterwards the folder you extracted is not needed any
  more. You can delete it.


-----------------------------------------------------------
  EVERY DAY - START AND STOP THE APP
-----------------------------------------------------------

  START: double-click the "HC Fashion House" shortcut on
  the Desktop, then click "Open App". The app opens in
  your web browser at:

    http://localhost:47371

  STOP: open the launcher again (the same shortcut), click
  "More options", then "Stop the app". Inside the app,
  Control Panel -> Stop Server does the same.

  The launcher's "More options" also has:

    Back up my data .......... saves a backup ZIP
    Restore a backup ......... puts a backup ZIP back
    Move to another PC ....... a ZIP to take to a new PC
    Open the backups folder .. shows the backup ZIPs
    Stop the app ............. stops the app
    Uninstall ................ removes the program and
                               keeps your books


-----------------------------------------------------------
  WHERE IS MY DATA? WHERE DO BACKUPS GO?
-----------------------------------------------------------

  Everything is in the program folder,
  %LOCALAPPDATA%\Programs\HC Fashion House :

    _system\data ............. invoices, customers,
                               settings
    _system\Saved Invoices ... saved invoice PDFs
    Backups .................. backup and Move ZIPs

  "_system" is hidden: in File Explorer click View ->
  Show -> Hidden items to see it.

  "Back up my data" writes a ZIP of the data folder into
  the Backups folder. Copy the newest one to a USB drive
  every week and keep the drive somewhere safe. Do not put
  backup ZIPs on OneDrive and do not e-mail them: each one
  holds your whole books.

  The app also copies your data every day by itself, and
  can put a second copy on a USB drive or a second disk:
  Settings -> Backup Management.


-----------------------------------------------------------
  RESTORE A BACKUP
-----------------------------------------------------------

    1. Open the launcher -> More options ->
       Restore a backup.
    2. Pick the backup ZIP (they are in the Backups folder).
    3. Check the numbers it shows, then click Yes.

  The app stops, your current data is saved first as
  "pre-restore-<date>.zip" in the Backups folder, and then
  the backup is put in place. When the window says Done,
  open the app again.

  Inside the app, Control Panel -> Choose Backup ZIP works
  the same way: the app closes while the restore runs.
  Open it again when the restore window says Done.

  A ZIP that is not an HC Fashion House backup is refused,
  and nothing is changed.


-----------------------------------------------------------
  MOVE TO ANOTHER PC
-----------------------------------------------------------

    1. Old PC: More options -> Move to another PC. It saves
       MOVE-HCFashionHouse-<date>.zip in the Backups folder.
    2. Copy that ZIP to a USB drive.
    3. New PC: install HC Fashion House (STEP 1 and 2).
    4. New PC: More options -> Restore a backup -> pick the
       MOVE ZIP.

  Saved invoice PDFs are not in backup or Move ZIPs. To
  take them along, copy the "_system\Saved Invoices" folder
  as well.


-----------------------------------------------------------
  IF SOMETHING GOES WRONG
-----------------------------------------------------------

  Find the message you see. Your invoices are never lost
  by any of these.

  "Please extract the ZIP first" / "Some files are missing"
      The ZIP was not fully extracted, or the launcher was
      opened from inside the ZIP. Go back to STEP 1.

  "Part of the app is missing"
      Files inside "_system" are gone - often removed by an
      antivirus. Ask for a fresh copy of the ZIP (see
      "Still stuck?" below).

  "Already installed on this computer"
      You opened the launcher of a new ZIP. Keep using the
      installed copy from the Desktop shortcut. The new
      folder is not needed; you can delete it.

  "Windows protected your PC"
      Click "More info", then "Run anyway" (see STEP 2).

  "This folder syncs to the cloud"
      The app is inside OneDrive, the Desktop or Documents,
      so your books are copied to the cloud. Ask your
      administrator to move it to the program folder.

  "Still starting..." / "The server has not answered in
  90 seconds"
      The first start after an install is slow (antivirus
      checks every new file). Wait a minute and open
      http://localhost:47371 in your browser. Still
      nothing? Close the black window and click Open App
      again.

  "Cannot connect to server" / "This site can't be
  reached" / a blank page
      The app is not running. Open the Desktop shortcut and
      click "Open App".

  "The app cannot write to its own folder"
      An antivirus setting ("controlled folder access") or
      a read-only drive blocks the program folder. Allow
      the folder in the antivirus, then try again.

  "Drive ... is almost full"
      The app needs about 400 MB free. Empty the Recycle
      Bin or delete old downloads.

  The app looks the same after a new version was installed
      Reload the page with Ctrl + F5.

  Still stuck?
      Contact your HC Fashion House administrator. Tell
      them the message you see; a photo of the screen
      helps.


-----------------------------------------------------------
  FOR THE ADMINISTRATOR
-----------------------------------------------------------

  Installing a new version (the app never updates itself):

    1. Launcher -> More options -> Back up my data. Copy
       the newest ZIP from the Backups folder to a USB
       drive.
    2. Launcher -> More options -> Uninstall. Only the
       program and its shortcuts go; the books, the saved
       PDFs and the Backups folder stay.
    3. Extract the new HC-Fashion-House ZIP, open its
       launcher and click Install. It finds the books in
       the program folder and keeps using them.
    4. Open the app and check the version under About.

  Optional - block the app's own Node.js from the internet
  with a Windows Firewall rule. The app only talks to this
  PC, so nothing changes for staff. Run PowerShell as
  administrator, put the shop user's folder name in place
  of <user>, and enter:

    New-NetFirewallRule -Direction Outbound -Action Block `
      -DisplayName "HC Fashion House - block app Node outbound" `
      -Program "C:\Users\<user>\AppData\Local\Programs\HC Fashion House\_system\node\node.exe" `
      -Profile Any
