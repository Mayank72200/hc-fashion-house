# Changelog

## 1.0.0 - first HC Fashion House release

The first release of HC Fashion House store billing and GST management.

- Billing, stock, purchases, expenses, clients, receipts, reports and GST
  returns, with all books kept on the shop PC.
- No outside connections: no update checks, no web fonts, no online help
  and no promotion screens. Google Drive, with the shop's own account, is
  used only when someone clicks "Save to Drive" or ticks the Drive box on
  a backup.
- The HC Fashion House name, icons and About page throughout.
- All existing terms presets kept, plus a new "HC Fashion House Store
  Terms" preset.
- Offline install: the release ZIP carries its own Node.js and packages.
  New versions are installed by the administrator; the app never updates
  itself.
- Safer data handling: a "Replace existing data" import choice that takes
  a snapshot first, backups kept on the PC rather than in synced folders,
  and tests that never touch live books.
